# LearoLab

LearoLab is an interactive adaptive learning app for kids built with React.

## Features

- Math Trail, Word Grove, and Science Lab
- Adaptive difficulty based on learner performance
- XP, levels, streaks, and badges
- Parent progress dashboard
- Multiple visual themes
- Browser-based progress saving with localStorage

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Upload this project to GitHub and import the repository into Vercel, Netlify, or another Vite-compatible host.
